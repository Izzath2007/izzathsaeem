Particle Interaction Lab

Move your pointer through the field to push glowing particles, draw connection lines, and experiment with the simulation settings.

Particles: 95 Mode: Repel Click to burst

Controls

Tune the playground and watch each particle react in real time.

How it works

Each dot has velocity, friction, boundary bounce, pointer force, and a distance-based line connection.

  • Hover near particles to repel or attract them.
  • Click inside the canvas for a ripple burst.
  • Use the sliders to change density and energy.

How to run

No install step is needed. Open index.html directly, or serve this folder locally for the browser-like workflow.

  1. Open a terminal in the project folder.
  2. Run python3 -m http.server 8000.
  3. Visit http://localhost:8000.
